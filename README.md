# markdown-note-organizer

一个开源的 AI Skill：把粘贴过来的杂乱笔记整理成结构清晰的 Markdown 笔记。

## 1. 项目解决什么问题

随手记的笔记往往是一段段口语化、没有结构、内容重复的文本，事后回看时很难抓住重点。让 AI 直接"整理一下"时，结果又常常不可控：丢失数据、自行脑补内容、为凑篇幅强行扩充。

本 Skill 为 AI 提供一套明确的整理规则，使其每次输出都稳定可靠：结构清晰、要点成列表、重复内容合并、废话去除，同时**保留全部原始关键信息，不编造、不强行扩充**。

## 2. 主要功能

- **自动分级标题**：一级标题定整篇主题，二级标题分话题，必要时用三级标题细分。
- **要点列表化**：叙述性、口语化内容提炼为无序列表；步骤或有时序的内容用有序列表。
- **合并重复内容**：同一内容多次出现时合并为一处；表述有差异时保留信息并集，不丢细节。
- **去除废话**：删除寒暄、口头禅、语气词和没有信息量的重复。
- **保留关键信息**：数字、日期、版本号、名称、术语、代码、命令、链接、公式和例子原样保留（含空格、符号和大小写写法）。
- **不编造、不扩充**：只重组原文内容，信息少时输出就短，不添加原文没有的评论或结论。
- **边界情况处理**：只有一两句话时不强加标题层级；已是 Markdown 的只做规范化去重，不推倒重来；多个话题混在一起时按话题分节或拆成多篇。

**不支持的功能**：网页抓取、PDF 读取、图形界面、文件读写。只处理用户在对话中粘贴的文本。

## 3. 安装方法

本项目是一个 Skill 定义（提示词规则），无需安装任何依赖包。

1. 克隆或下载本仓库。
2. 将 `skills/markdown-note-organizer` 整个文件夹复制到你所用 AI 工具的技能目录下，例如 Trae 的 `.trae/skills/` 目录。
3. （可选）运行结构校验，确认 Skill 文件完整（需要 Python 3，仅使用标准库）：

```bash
python quick_validate.py
```

输出 `校验通过` 即表示结构符合规范（frontmatter 完整、name 与目录一致、openai.yaml 存在且有效）。

## 4. 使用方法

在支持 Skill 的 AI 助手对话中，把杂乱的笔记直接粘贴进去，并说明要"整理笔记"（如"帮我整理成 Markdown 笔记"），即可触发本 Skill。

- 仅支持粘贴文本输入；如需整理网页或 PDF 内容，请先自行复制文本再粘贴。
- 如对整理结果有疑问，可要求 AI 说明做了哪些合并或删除（Skill 会用一两句话简要说明）。

## 5. 输入输出示例

**输入（粘贴的杂乱笔记）：**

```text
周五的会 开会的人说 下周三前要把用户调研问卷做完 老张负责设计部分
问卷至少要有10道题 问卷 小李那边等这个结果 下周三前
对了问卷要10道题以上 最好包含满意度打分
```

**输出（整理后的 Markdown）：**

```markdown
# 用户调研问卷工作安排

## 任务要求
- 下周三前完成用户调研问卷
- 问卷至少 10 道题
- 最好包含满意度打分

## 分工
- 老张：问卷设计部分

## 相关依赖
- 小李在等待该结果
```

**短文本边界示例**（信息少时不强行扩充标题层级）：

```text
健身计划：每周3练 胸 背 腿各一天 有氧放在练后20分钟
```

```markdown
- 每周 3 练：胸、背、腿各一天
- 有氧放在训练后 20 分钟
```
